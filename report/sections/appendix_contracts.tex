\subsection{UserProfile Contract}

\textbf{File:} \texttt{src/UserProfile.sol} (50 lines)

Manages user registration and profile storage with role assignment (Client/Freelancer). Key components:
\begin{itemize}
    \item \texttt{Profile} struct: userID, username, cid (IPFS), role, userAddress
    \item Mappings: \texttt{\_profiles} (address → Profile), \texttt{\_usernameOwner} (username → address)
    \item Functions: \texttt{setProfile}, \texttt{getProfileByAddress}, \texttt{getUserByUsername}
\end{itemize}

\textbf{Security Features:} Username uniqueness enforcement, input validation, profile updatesupport with username change handling.

\subsection{JobsContract}

\textbf{File:} \texttt{src/Jobs.sol} (120 lines)

Handles job creation, escrow management, and payment release. Key components:
\begin{itemize}
    \item \texttt{Job} struct: jobID, jobCID, deliverableCID, completed, client, freelancer, amount, clientApproved, freelancerApproved
    \item Mappings: \texttt{\_jobs} (jobID → Job), \texttt{\_clientJobIDs} (address → jobID[])
    \item Functions: \texttt{CreateJob} (payable), \texttt{HireFreelancer}, \texttt{MarkFLJobCompleted}, \texttt{MarkClientJobCompleted}, \texttt{\_releaseFunds} (private)
\end{itemize}

\textbf{Security Features:} Checks-Effects-Interactions pattern, zeroing amount before external call, mutual approval requirement for fund release.

\subsection{ProposalsContract}

\textbf{File:} \texttt{src/Proposals.sol} (80 lines)

Manages proposal submission and approval workflow with automatic freelancer hiring. Key components:
\begin{itemize}
    \item \texttt{Proposal} struct: proposalID, proposalCID, jobID, approved, freelancer
    \item Mappings: \texttt{\_proposals}, \texttt{\_jobProposalIDs}, \texttt{\_freelancerProposalIDs}
    \item Functions: \texttt{CreateProposal}, \texttt{ApproveProposal}, \texttt{getProposalsByJobID}, \texttt{getFreelancersProposals}
\end{itemize}

\textbf{Integration:} Uses \texttt{IJobsContract} interface to verify job ownership and trigger freelancer hiring on approval.

\subsection{Contract Interactions}

The three contracts operate independently for their primary functions: UserProfile handles identity, JobsContract manages escrow and payments, and ProposalsContract orchestrates the bidding process. Cross-contract calls are minimal: ProposalsContract calls JobsContract only for hiring verification and execution.
