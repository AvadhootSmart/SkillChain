SkillChain is a decentralized freelance marketplace built on Ethereum blockchain technology that eliminates intermediaries and establishes trust through smart contracts. The traditional freelance industry faces significant challenges including high commission fees (typically 10-20\%), payment delays of 5-14 days, lack of transparency in dispute resolution, and data privacy concerns due to centralized storage, affecting millions of freelancers and clients worldwide. This project presents the complete architecture, design decisions, algorithms, and implementation details of the SkillChain platform, addressing these challenges through direct peer-to-peer transactions, smart contract escrow for secure payment holding and conditional release, decentralized IPFS storage for data permanence and censorship resistance, and transparent operations with all transactions verifiable on the blockchain. The platform implements three interconnected smart contracts: UserProfile Contract for managing user identities and roles, JobsContract for handling job creation, escrow management, and payment release, and ProposalsContract for managing proposal submission and approval workflow. The frontend is built using modern web technologies including Next.js, React, TypeScript, and Tailwind CSS, with Web3 integration through wagmi and RainbowKit. Security considerations include re-entrancy protection through the Checks-Effects-Interactions pattern, comprehensive input validation, and multi-party approval for fund release, with the system thoroughly tested using the Foundry framework achieving 100\% coverage of contract functions. The project demonstrates the feasibility of decentralized freelance marketplaces and provides a foundation for future enhancements including Layer 2 integration, reputation systems, and decentralized dispute resolution.
