\section{Test Execution}

\subsection{Running Tests}

\begin{lstlisting}[language=bash, caption={Test Execution Commands}]
# Run all tests
forge test

# Run with gas reporting
forge test --gas-report

# Run specific test file
forge test --match-path test/Jobs.t.sol

# Run specific test
forge test --match-test test_CreateJob

# Run with verbosity
forge test -vvv

# Run with coverage
forge coverage
\end{lstlisting}

\section{Integration Testing}

\subsection{End-to-End Workflow Testing}

Integration tests verify the complete workflow:

\begin{enumerate}
    \item \textbf{User Registration Flow}
    \begin{itemize}
        \item Create client profile
        \item Create freelancer profile
        \item Verify profile retrieval
    \end{itemize}
    
    \item \textbf{Job Lifecycle Flow}
    \begin{itemize}
        \item Client creates job with escrow
        \item Freelancer submits proposal
        \item Client approves proposal
        \item Freelancer marks complete
        \item Client marks complete
        \item Verify payment release
    \end{itemize}
    
    \item \textbf{Error Scenarios}
    \begin{itemize}
        \item Attempt to create job without funds
        \item Attempt to approve own proposal
        \item Attempt to mark complete without hiring
        \item Attempt double payment release
    \end{itemize}
\end{enumerate}
